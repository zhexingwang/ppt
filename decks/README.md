## 新しい資料を追加するとき

1. `decks/_template/` をコピーして `decks/NN_短い名前/` を作る
2. PPT（と必要なら原稿・プレビュー）をそのフォルダへ置く
3. `README.md` に目的・対象・構成・ファイル一覧を書く
4. この一覧表に 1 行追加する

番号 `NN` は作成順です。生成スクリプトの出力先も、原則このフォルダに揃えます。
