# Copilotで作る発明開示書

## 目的

ANAQUA形式の発明開示書を、CopilotとPatentSQUAREで素案まで作る手順を説明する。
初めて書く人が、各Stepのゴールを見失わないようにした。

## 今回の直し

| コメント | 反映 |
|---|---|
| 以前との違いがいらない | 対比の説明をやめ、いまの進め方だけにした |
| AIの解答例が短すぎる。本当の回答を | 各StepにGrokが返す長さの回答例を載せた |
| 「先行」を「先行特許」に | 用語を先行特許にそろえた |
| 「終わったら」はゴールの意味に | 手順図の見出しを「ゴール」にした |
| 6枚目の①と④だけオレンジ | 番号の色をすべて紺にそろえた |

## 概要

- 対象: 初めて発明開示書を書く人
- 枚数: 13（16:9）
- 例の発明: 安全計装ロジック自動構築ツール
- 回答例のラベル: 回答例（Grok）。Copilotでも同じ聞き方でよい

## スライド構成

| # | 内容 |
|---|---|
| 1 | 表紙 |
| 2 | この資料で伝えたいこと |
| 3 | 使う前の約束（セキュリティ／AIは支援者） |
| 4 | 道具（Copilot / PatentSQUARE） |
| 5 | 開示書の項目 |
| 6 | 全体の手順と、各Stepのゴール |
| 7–12 | Step 0〜5（ゴール → 確認 → やること → 対話例） |
| 13 | 図面（Graphviz） |

再生成: `python3 generate_invention_disclosure.py`
