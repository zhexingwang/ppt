# Copilotで作る発明開示書（訂正反映）

## 目的

ANAQUA形式の発明開示書を、CopilotとPatentSQUAREで素案まで作る手順を説明する。
元スライド（2026/06/12）へのコメントを反映した改訂版。

## 反映したコメント

| コメント | 反映 |
|---|---|
| プロンプト例は質問だけでなくAI回答も | 各Stepの右に「あなた／Copilot」のやり取り |
| 文字が多い。集約したい | 20枚→13枚。各Stepはゴール＋やること3点 |
| 各Stepのゴールがわかりにくい。字数は不適切かも | 字数目安をやめ、「できた状態」で定義 |
| 先行特許調査を先に、そのあとクレーム | Step 1が調査、Step 4がクレーム |

## 概要

- 対象: 初めて発明開示書を書く人
- 枚数: 13（16:9）
- 例の発明: 安全計装ロジック自動構築ツール

## スライド構成

| # | 内容 |
|---|---|
| 1 | 表紙 |
| 2 | この資料で伝えたいこと |
| 3 | 使う前の約束（セキュリティ／AIは支援者） |
| 4 | 道具（Copilot / PatentSQUARE） |
| 5 | 開示書の項目 |
| 6 | 手順全体（調査→具体化→差→クレーム） |
| 7–12 | Step 0〜5（ゴール＋対話例） |
| 13 | 図面（Graphviz） |

再生成: `python3 generate_invention_disclosure.py`
