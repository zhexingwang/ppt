# 自己紹介（王 者興）

## 目的

氏名・出身・来日〜博士・横河での経歴・PCP様との協業を、**1枚のタイムライン**で伝える。
参考インフォグラフィック（紺×黄）のテイストに合わせた発表用スライド。

## 概要

- 作成日: 2026-07-31
- 対象聴衆: 社内外の初対面・協業先（PCP様含む）
- 枚数: 2（画像版 + 編集可能版）。単独ファイルもあり
- ステータス: 利用可
- 生成: `python3 generate_self_intro.py`

## スライド構成

| # | 種類 | 内容 |
|---|---|---|
| 1 | 画像版 | イラスト付き全面インフォグラフィック（発表向き） |
| 2 | 編集可能版 | 同じ内容を図形＋アイコンで構成。テキスト編集可 |

編集可能版の4アイコン: 西安 / 来日 / 研究室 / 横河

## ファイル

| ファイル | 説明 |
|---|---|
| `self_intro.pptx` | 画像版 + 編集可能版（2枚） |
| `self_intro_image_only.pptx` | 画像版のみ（PowerPoint互換性重視） |
| `self_intro_editable_only.pptx` | 編集可能版のみ |
| `previews/` | PNG プレビュー |

## メモ

- 透明PNGやコネクタ図形が PowerPoint の修復ダイアログを誘発したため、不透明PNG＋LibreOffice再保存済み
- 開けない場合は `self_intro_image_only.pptx` を先に試す
- 素材はリポジトリ直下の `assets/`（全体画像・円形アイコン）
